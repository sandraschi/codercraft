CoderCraft is an ArtCraft-tier local-first agentic integrated development environment (IDE) that subsumes the capabilities of Claude Desktop, OpenCode, Cursor, Zed, and Antigravity (AGY) into a unified, zero-runtime-tax native binary.

Built in 100% native Rust (egui 0.37 + wgpu) on Port 14128, CoderCraft delivers sub-millisecond rendering, an instant (<30ms) startup time, and a minimal ~35MB RAM footprint with zero Electron bloat.

---

Key Superpowers

1. Dual Cognitive Modalities:

  • 📋 Plan Mode: Non-destructive codebase analysis, instruction discovery (AGENTS.md, CLAUDE.md, .cursorrules), and phased architectural roadmaps.
  • 🔨 Build Mode: Active AST diff generation, atomic code patch application, and autonomous test/linter verification loops.

2. Interactive Stigmergic Swarm Supervisor:

  • Live ComfyUI / MaterialCraft style Bézier node graph connecting 5 specialist agents (Architect-01, Synthesizer-02, ClippyGuard-03, TestRunner-04, DocSync-05) with animated pheromone flow particles.

3. Multi-Display Quad Layout Architecture:

  • Provisions up to 4 native displays:
  • Display 1 (Primary): Code Editor & Central Agentic Chat.
  • Display 2 (Terminal): Interactive PowerShell/Bash sandbox & streaming linter.
  • Display 3 (Supervisor): Stigmergic swarm node graph & task blackboard.
  • Display 4 (Fleet Depot): One-click project launcher & split diff inspector.

4. Fleet Craft Project Depot:

  • Direct mission control for all 12 local-first Craft applications (DatabaseCraft, AppCraft, RobotCraft, MoneyCraft, DJCraft, ModCraft, WriterCraft, CoderCraft, TravelCraft, MakerCraft, SportsCraft, DemoCraft).
  • Real-time TCP socket probing measures exact network ping latencies (● ONLINE (1ms) / ○ OFFLINE).

5. Multi-Buffer Code Studio & AST Symbol Outline:

  • Multi-tab file editing with dirty-state tracking (*), instant save (Ctrl+S), and auto-extracted top-level function, struct, enum, and trait jump navigation.

6. Zero-Panic Safety Guarantee:

  • Mandatory #![deny(clippy::unwrap_used)], #![deny(clippy::expect_used)], and #![deny(clippy::panic)] enforced across all crates.

Lineage — the Storytold craft-app pattern

Storytold ArtCraft (storytold/artcraft — "the IDE for artists") was the starting point. The 16 craft apps in the Storytold stable each ship one binary that is both the human CLI and the agent MCP server (stdio), headless-first, with run.json + report artifacts. That modus operandi and harness is what this repo implements; the code here is independent, the pattern is shared.

Summary (do not drift; edit ../PRD.md instead)

CoderCraft is the local-first agentic IDE: Plan mode (read-only codebase

exploration, AGENTS.md/CLAUDE.md/.cursorrules discovery, phased

roadmaps) plus Build mode (AST diffs, atomic patches, test/linter gates),

with a stigmergic 5-agent supervisor swarm and a fleet depot (12 craft apps,

live TCP probe) in one native Rust binary (~35 MB RAM, <30 ms startup).

Tier mapping

  • Tier 1: workspace + deny gates + Command::dispatch + deterministic edit

concept + L3 parity test + release size note.

  • Tier 2: live linter/test runners (Clippy, Ruff, Biome) streaming in the

terminal display; craft-ai-core token telemetry (Ollama local, cloud

optional).

  • Tier 4: quad-display studio, egui_kittest goldens, current-user NSIS

installer, cold-boot table in README.
